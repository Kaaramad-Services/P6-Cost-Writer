Method A · Round-trip recommended — no warning

In P6: File → Export → Spreadsheet (XLSX), tick Expenses, export your project. Drop that file here — the tool writes your cost into its PROJCOST sheet and leaves everything else (including P6's USERDATA) untouched, so P6 re-imports its own file with no "user preferences" warning.

Method B · Generate from scratch works — P6 may ask to confirm

No P6 export handy? This builds a PROJCOST + USERDATA workbook. On import P6 may warn that "user preferences could not be found" — that is expected for a generated file; click Yes (on a project copy) and the cost loads.

Either way: import into a copy of the project first (File → Import → Spreadsheet → XLSX), and verify the imported total equals the "Cost matched" stat above. CSV cannot be imported by P6 — that's why this tool now produces XLSX. Note your P6 is Professional 23 and currency is Saudi Riyal.
